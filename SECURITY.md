# Seguridad y privacidad

## Alcance

Ecuador Vivo es un sitio estático publicado mediante GitHub Pages. El repositorio no contiene
credenciales, claves privadas ni información personal de usuarios. Las capas externas se consultan
directamente desde los proveedores documentados y pueden estar sujetas a sus propios términos,
límites y registros de acceso.

## Reportar una vulnerabilidad

No publiques secretos, tokens ni detalles explotables en una incidencia pública. Para reportar un
problema sensible, contacta al mantenedor mediante el perfil de GitHub del repositorio e incluye:

- una descripción clara del problema;
- pasos mínimos para reproducirlo;
- impacto esperado;
- una propuesta de mitigación, si la tienes.

Los errores ordinarios del atlas, problemas de datos o fallos visuales deben abrirse mediante las
plantillas públicas de incidencias.

## Buenas prácticas del proyecto

- Las acciones de GitHub usan permisos mínimos de lectura.
- Las fuentes remotas y sus condiciones se documentan en `documentation/data-sources.md`.
- Los datos demostrativos están separados de los catálogos científicos.
- Las actualizaciones se revisan mediante validación automática antes de publicarse.
